# InternCircle Task 2: Interactive Calculator & Unit Converter

## Project Overview
A beginner-friendly Python command-line application that performs basic arithmetic operations and converts common units.

## Features
- Addition, subtraction, multiplication, and division
- Kilometers to miles conversion
- Celsius to Fahrenheit conversion
- Input validation and error handling
- Protection against division by zero
- Menu-driven interface using loops and functions

## Technologies Used
- Python
- Built-in Python functions and control structures

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `python main.py`.
